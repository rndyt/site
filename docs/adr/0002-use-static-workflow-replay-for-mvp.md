# Use a static workflow replay for the MVP AI demo

The first AI demo will be a deterministic workflow replay with fixed inputs and outputs, showing the problem, AI proposal, human judgment, and verification result. This keeps the MVP reproducible and avoids API keys, runtime cost, privacy concerns, and model drift; a live model playground remains a possible later extension once there is a concrete interaction worth supporting.

**Status**: accepted

**Considered Options**: Live model playground; external demo link only.
