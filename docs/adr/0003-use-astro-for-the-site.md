# Use Astro and TypeScript for the site

The site will use Astro with TypeScript because it is primarily a Markdown-driven technical publication with a small amount of isolated interactivity for the workflow replay. Astro keeps the default output static and content-focused while allowing interactive islands where they add evidence; a full application framework is deferred until the site needs server-side behavior.

**Status**: accepted

**Considered Options**: Next.js with TypeScript; plain HTML, CSS, and JavaScript.
